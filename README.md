# AI Data Quality & Root-Cause Analysis Copilot

## Project Overview
This project uses Python to analyze datasets and identify common data quality issues. It generates reports to help users understand the quality of their data.

## Objectives
- Detect missing values.
- Identify duplicate records.
- Detect numerical outliers using the IQR method.
- Check basic data validation rules.
- Generate downloadable CSV reports.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- GitHub

## Project Files
- `ai_data_quality_copilot.ipynb` — Python notebook containing the analysis.
- `data_profile_report.csv` — Dataset profiling report.
- `data_quality_report.csv` — Data quality findings report.

## How to Run
1. Open the notebook in Google Colab.
2. Upload a CSV or Excel dataset when prompted.
3. Run all notebook cells in order.
4. Review the generated reports.

## Current Status
The initial Python-based data quality analysis and CSV report generation are implemented.
